# analisis-consumos-pigs-2026

## Titulo y descripción general
Análisis de los consumos del Parque Industrial PIGS 2026.

Este proyecto analiza los consumos de agua potable del Parque Industrial PIGS. Utiliza datos registrados desde Enero 2022 hasta Octubre 2026.

A partir de un dataset con mas de 6.000 registros, se aplicaron técnicas de limpieza, análisis exploratorio y visualización en Python. Adicionalmente se elaboró un dashboard en Power BI.

## Objetivo del proyecto
- Conocer la evolución de los consumos de agua potable Parque Industrial.
- Conocer los tipos de industrias que mayores consumos presentan.
- Analizar la respuesta de la empresa prestadora del servicio de agua ante un aumento significativo en la demanda.

## Dataset utilizado
- Fuente: Con SQL de la base de datos de empresa prestadora del servicio.
- Formato: EXCEL con 13 variables iniciales (diccionario de columnas dentro del analisis Python).
- Cantidad de Registros: 6.334.
